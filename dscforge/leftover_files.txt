# Names of files and folders that AI agents and working notes leave behind. Used by the leftover-file rule.
#
# Format: one entry per line; lines starting with # are ignored.
# - A plain name matches a file or a folder with that name anywhere in the tree, ignoring letter case
#   (agents.md, Agents.md and AGENTS.md all match). An entry ending in .md also matches the same name ending in
#   .txt, .yaml, .yml, .json and .toml.
# - An entry with * is a glob over the name (*.instructions.md).
# - An entry with / is a path pattern, matched against the path inside the project (.github/instructions).
# A matching folder is reported once and not searched further.
# This list prefers false alarms over misses: every hit is only "possibly a leftover". To be quieter, delete an
# entry or put # in front of it. Add your own names at the end.
